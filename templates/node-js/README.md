# Node.js Starter Sandbox

Welcome to your PodForge Node.js workspace!

## Running the Application
- The application automatically binds to port `3000`.
- To start or restart the server, run:
  ```bash
  node index.js
  ```
  or
  ```bash
  npm start
  ```

## Installing Dependencies
You have full access to `npm` via the integrated terminal:
```bash
npm install <package-name>
```

The live web preview panel is connected to port `3000` and will display your server output in real-time.
