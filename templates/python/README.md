# Python Starter Sandbox

Welcome to your PodForge Python workspace!

## Running the Application
- The starter HTTP server binds to port `3000`.
- To start or restart the server, run in the terminal:
  ```bash
  python3 main.py
  ```
  or
  ```bash
  python main.py
  ```

## Installing Dependencies
You can install packages using `pip`:
```bash
pip install -r requirements.txt
```

The live web preview panel is connected to port `3000` and displays your server output in real-time.
